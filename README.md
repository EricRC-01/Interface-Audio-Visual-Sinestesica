# Interface Audio-Visual Sinestesica

## Conceito geral
Interface que visa captar o áudio de um show ao vivo e convertê-lo em imagens abstratas e artisticamente expressivas, baseadas na interpretação visual das ondas sonoras e perspectivas artiticas das musicas que estão sendo tocadas
